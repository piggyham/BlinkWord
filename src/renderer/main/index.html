账号与同步

单词本多端同步:自建服务器 或 坚果云网盘

自建服务器

当前同步方式

需先运行「启动同步服务器.bat」(或把 server/ 放到局域网电脑/NAS/云服务器);在多台设备上填同一服务器地址并登录同一账号,即可互相同步。

?

登录期间,单词本的任何改动(划词存词、复习进度、重要度)都会在约 5 秒后自动同步。

坚果云 WebDAV

当前同步方式

词库以单个 JSON 文件存在你自己的坚果云网盘里,无需自建服务器、不经过第三方;多台设备填同一账号即可互相同步(合并规则与自建服务器一致,不会互相覆盖)。

☁

连接期间,单词本的任何改动都会在约 5 秒后自动同步;断开只清除本机保存的应用密码,云端文件保留。

设置

划词翻译

取词以系统无障碍接口(UI Automation)直读选区为主,不占用你的剪贴板;仅个别不支持该接口的应用会临时借用剪贴板模拟复制,并在约 1 秒内自动恢复。

翻译服务 (从上到下依次尝试,第一个成功者生效)

免 key:微软翻译、MyMemory。LLM 类(DeepSeek/智谱/Kimi/Ollama 等)质量更好但稍慢,一次返回译文+音标+释义;DeepSeek 约每百万 token 1~2 元,翻译有本地缓存,同词只调一次。Key 只保存在本机数据文件中。
